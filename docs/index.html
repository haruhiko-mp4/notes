Hearing notes

"Start"を押してから、4秒おきにランダムな音が鳴ります。
聞こえてくる音階に対応する鍵盤UIを押して回答しましょう。

PCではキーボードからも音を鳴らして回答することができます。
(Q W E R T Y U I に白鍵、2 3 5 6 7に黒鍵が対応します。)

If you are using a PC, you can also answer using the keyboard.
(Q, W, E, R, T, Y, U, I, 2, 3, 5, 6, 7)
